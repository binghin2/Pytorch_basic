# Pytorch_basic
PyTorch fundamentals study notebooks, written in Google Colab.

| Notebook | Topic |
|---|---|
| `Matrix_basic.ipynb` | Tensor creation, dtype/shape, zeros/ones, element-wise arithmetic |
| `Matrix_basic2.ipynb` | Tensor indexing and slicing in 1D/2D/3D, advanced indexing |
| `torch_function.ipynb` | Random tensors (`randn`/`rand`), math functions, NaN/Inf checks |
| `LinearRegression.ipynb` | Linear regression with `nn.Linear`, MSE loss, and SGD training loop |
| `binary_classification.ipynb` | MLP binary classifier on synthetic 2D Gaussian data |
| `CNN_basic.ipynb` | Loading and inspecting a deep CNN trained on CIFAR-10 |
| `test.ipynb` | Environment check (scratch) |
